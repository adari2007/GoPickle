# GoPickle UI Project

This project contains the user-facing apps:

- `web/` - responsive website (desktop + mobile web)
- `mobile/` - Expo React Native app
- `shared/` - shared UI/domain typings

## Run

```bash
cd /Users/tadar01/Documents/GitHub/GoPickle
npm run install:web
npm run install:mobile
npm run dev:web
npm run dev:mobile
```

## Env

- Web: `web/.env` with `VITE_API_BASE`
- Mobile: `mobile/.env` with `EXPO_PUBLIC_API_BASE`
